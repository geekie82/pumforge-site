Getting started.

Everything you need to install, configure, and run pumFORGE on your own machine.

Install on Linux

Download the .deb then run sudo dpkg -i pumforge_1.3.0_amd64.deb. The installer sets everything up.

Hardware

8GB+ RAM for text. An NVIDIA GPU (12GB+) for voice + image gen. CPU works for chat.

Models

pumFORGE ships its own inference engine. Use the built-in Model Browser to download models.

Mobile & LAN

Access from any device on your network. Bind to 0.0.0.0 with auth for remote access.

Forgey co-worker

Open the Terminal and click Friend. Forgey shares your shell — ask, approve, and run.
