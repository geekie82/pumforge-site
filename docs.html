Docs

Getting started

Everything you need to install, configure, and run pumFORGE on your own machine.

💻

Install on Linux

Download the .deb, then run sudo dpkg -i pumforge_1.1.0_amd64.deb. The installer sets up everything automatically.

🔋

Hardware

8GB+ RAM for text. An NVIDIA GPU (12GB+) is recommended for voice and image generation. CPU-only works fine for chat.

🎬

Models

pumFORGE ships its own inference engine. Use the built-in Model Browser to download thousands of open models — no external runtime required.

🌐

Mobile & LAN

Access pumFORGE from any device on your network. Bind to 0.0.0.0 with authentication for remote access.

📱

Remote access

Browser mic/camera work over HTTPS. Set up a reverse proxy with TLS for full remote voice access.

🧺

Support

Questions? Reach support at support@pumforge.com.
