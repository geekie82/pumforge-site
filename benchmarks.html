Read this honestly. A ~4B fully-local model will not match frontier cloud models on hard coding benchmarks — and we won't pretend it does. What pumFORGE proves is that a capable coding assistant runs entirely on your hardware with audit, consent and rollback, at a score that is reproducible and only gets better as you upgrade the model. We target best-in-class among fully-local agents, not a cloud arms race.

Methodology

Reproducible, not cherry-picked.

Fixed harness

The suite, prompts, temperature (0.1), max tokens (768) and engine build are pinned so anyone can re-run and get the same result.

Runs on your PC

Launch Settings → Automation → "Run benchmark" and it executes on your machine in minutes, writing a dated report to your local data folder.

Full HumanEval support

The harness reads the standard HumanEval jsonl format — drop in the full 164-problem set and it will run it the same way.
