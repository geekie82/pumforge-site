How it works

You talk (or type) → it transcribes → thinks → replies out loud — using tools, your documents, memory, or the PC along the way.

FAQ

Does it need the internet?

No. The model, speech, and everything else run locally on your machine. You only need internet if you use optional tools like web search, weather, or stock prices.

Is my data private?

Yes. Chats, files, memories, and your cloned voice stay on your own disk. Nothing is sent to a pumTALK cloud (there is none).

What hardware do I need?

An 8GB+ machine is fine for text. For the best voice experience, an NVIDIA GPU (12GB+) is recommended for faster speech and cloning.

Which AI model does it use?

It works with Ollama or LM Studio, so you can use any local model you like and swap models freely.

Can it really control my PC?

Yes — files, apps, clipboard, screenshots, and more. Every risky action asks for your approval before it runs.
